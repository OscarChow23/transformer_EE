# pcnumu/plots: talk and thesis figure scripts

- `talks/YYYYMMDD_name/`: the scripts that made one talk's figures, kept as the record. Outputs are in
  `/data/nova/chow/pcnumu-analysis/talks/`, never in this repository.
- The plot style is `pcnumu/core/style.py` (house style, fonts bundled); rules in `pcnumu/AGENTS.md`.

Folders with an `IMPORTED.md` were copied here on 2026-11-17 from the talk bundles where they were
written; they still use the bundle's own copy of the style and its absolute paths.
