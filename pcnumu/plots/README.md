# pcnumu/plots: figure scripts for talks and the thesis

- `style/`: the shared ROOT-like plot style (`rootstyle.py`). Its TeX Gyre Heros fonts are not
  in git; they are in `/data/nova/chow/pcnumu-analysis/talks/20261106_talk-plots/style/fonts/`.
- `talks/YYYYMMDD_name/`: the scripts that made one talk's figures. Outputs go to
  `/data/nova/chow/pcnumu-analysis/talks/`, never into this repo.

Folders with an `IMPORTED.md` were copied here on 2026-11-17 from the talk bundles where they
were written; the originals stay next to their outputs.
