# Fonts

TeX Gyre Heros (regular, italic, bold, bold italic), a free Helvetica-like font from the GUST
e-foundry, distributed under the GUST Font License (https://www.gust.org.pl/projects/e-foundry/licenses).
Bundled so `pcnumu/core/style.py` gives identical figures on every machine without a system install.
If the files are missing, the style falls back to DejaVu Sans.
